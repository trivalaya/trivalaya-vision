## 4. TRAPS A FRESH CONTEXT CANNOT REDISCOVER CHEAPLY

**1. `appv2` hard-inserts `/home/claudeuser/trivalaya-vision` into `sys.path`.**
`_mask_query_image_meta` contains `sys.path.insert(0, "/home/claudeuser/trivalaya-vision")`.
Run naively from the worktree and the mask path silently imports **MAIN's**
`src.*` while your direct estimator calls use the worktree — a split
measurement that looks fine and is wrong. Every harness here defuses it by
pre-importing `src.pipeline_manager` / `src.math_utils` with the worktree at
`sys.path[0]` (so `sys.modules` already holds them), then **asserting**
`src.math_utils.__file__` resolves under `--vision-root` and aborting if not.
**Use the harnesses. Never call `_mask_query_image_meta` directly from an
ad-hoc script.**

**2. `cv2.setNumThreads(1)` is mandatory.** OpenCV keeps its own thread pool;
`OMP_NUM_THREADS` does not bound it. The first launch (3 workers, unpinned)
drove **load average 9.2 on 4 vCPU** and would have starved the live search
service. Every tool here pins it. Worker count then equals core count.
Consequence: elapsed times in this run are **not** comparable to the Bar 0
run's — A/B contrast only. (The latency leg is retired anyway.)

**3. Bar 2's golden reference** is `_golden_pre_m1` in
`tests/test_bg_corner_local_trust.py` — a **frozen verbatim copy** of the
shipped function at commit `a00f502`. It exists because comparing the gate
against itself proves nothing. If `detect_background_histogram` is edited
again, do **not** update the golden to match; that would erase the property
being asserted.

**4. Bar 3 uses harness-computed `mask_area_fraction`.** Production has **no**
no-op telemetry — `_mask_query_image_meta` returns only
`{masked, mask_fallback_reason, n_detections}`. The M1 work order claimed this
telemetry was "now first-class"; it is not, and the owner ruled 2026-07-28 that
the brief was wrong (not §7 of the Bar 0 doc), that it must **not** be built in
this session, and that the bar gates on the no-op **count**, not the
instrument. The harness computes area fraction by proxying `analyze_image` and
measuring the largest contour — validated against the prior run (max |area
delta| 0.0037; no-op count 12 vs 12 MATCH). Threshold: `masked==True AND
area_fraction > 0.9` (a real circular coin caps at π/4 ≈ 0.785).
